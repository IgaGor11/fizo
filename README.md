# EzyFizi — офлайн-тренажёр формул (ФИПИ 2026)

Полностью локальное iOS-приложение (iOS 16+, Swift + SwiftUI, MVVM).
Без сервера, без интернета, без подписок. Данные — `FizikaEGE/formulas.json`
по кодификатору ФИПИ 2026: 5 разделов, все темы, ~90 формул с LaTeX,
обозначениями, единицами СИ, мнемониками и уровнями сложности.

## Наука внутри

- **Retrieval practice** — карточки с активным припоминанием и самооценкой 1–4.
- **Spaced repetition + FSRS** (`FizikaEGE/FSRS.swift`) — трёхкомпонентная модель
  памяти (Retrievability / Stability / Difficulty), веса FSRS-4.5, fuzz интервалов.
- **Мнемоники** — у каждой формулы поле `mnemonic`.
- **Геймификация** — XP, ранги («Новичок» → «Профессор физики»), достижения,
  мгновенная обратная связь (анимация + вибрация + конфетти), без лидербордов.

## Рендер формул

Свой нативный мини-рендер LaTeX (`FizikaEGE/LatexView.swift`, SwiftUI, офлайн):
дроби, корни, индексы, степени, векторы, греческие буквы, `\mathcal{E}`,
`\text{}`, `\cos/\sin`, `\cdot/\times/\pm/\sum`. Ноль зависимостей —
сборка работает без доступа к сети. При желании можно подключить SwiftMath:
код уже изолирован в одном `LatexView`.

## Режимы тренировки

1. Карточки (самооценка «Не помню / Смутно / Помню / Легко» → FSRS).
2. Выбор из 4 (дистракторы из той же темы).
3. Ручной ввод LaTeX (толерантная проверка: пробелы, `\cdot`, порядок слагаемых)
   со **своей формульной клавиатурой**: три вкладки (123 / αβ / fx), греческие
   буквы, операторы, LaTeX-шаблоны (дробь, степень, индекс, корень, вектор —
   курсор встаёт внутрь скобок), вставка в позицию курсора, ⌫. Всё офлайн.
4. Сборка из блоков.
5. Смешанный Adaptive Mix (слабые → ввод/сборка, сильные → карточки).

## Уровни формул 1–10

Порог повышения `round(3 + уровень × 1.5)`, ошибка → −1. Названия:
1–2 «Новичок», 3–4 «Ученик», 5–6 «Практик», 7–8 «Знаток», 9–10 «Эксперт».
Уровень удлиняет интервал FSRS. Шкала для учителя: 1–3 «Не освоено»,
4–6 «Частично», 7–8 «Освоено», 9–10 «Отлично».

## Статистика и отчёт

Глобальная (кольцо, streak, heatmap 12 недель, кривая активности),
по разделам, по темам (топ-3 проблемных), по каждой формуле
(точность, интервал, следующая дата, история, кривая забывания R(t),
среднее время, разбивка по режимам). Отчёт для учителя — локальный PDF
(`TeacherReport.swift`) с рекомендациями, расшаривание через AirDrop/Mail/Telegram.

## Сборка

Локально на Mac с Xcode 16:

```bash
brew install xcodegen
xcodegen generate
open FizikaEGE.xcodeproj
```

Неподписанный IPA для Sideloadly собирается workflow
`.github/workflows/ios-ipa.yml` (запуск вручную или по тегу `ios-*`):
`xcodebuild archive` с `CODE_SIGNING_ALLOWED=NO` → `Payload/*.app` → ZIP →
`FizikaEGE-unsigned.ipa` в артефактах.
